# 模拟信号高精度采集系统
## 📋 项目简介

基于 Qt 框架和 FTDI FT600 开发的高速模拟信号采集系统，支持多通道同步采集差分电压信号，应用于精密电子测试和科研实验。系统采用先进的三线程并行通信架构，实现了高达数兆字节/秒的 USB 高速数据传输吞吐量。

## 主要特性

### 高性能数据采集
- **多通道同步采集**：A组8通道 / B组4通道差分电压信号
- **高精度ADC**：20位精度，电压范围 -5V ~ +5V
- **实时数据传输**：基于 FTDI FT600 的高速 USB3.0 通信
- **三线程架构**：数据发送、接收、处理线程并行运行

### 数据可视化
- **实时波形显示**：支持多周期均值和单周期数据显示
- **温度监控**：A组1路 / B组3路 NTC温度传感器
- **功率监测**：实时电压、电流、功率计算与显示
- **数字IO状态**：6路数字输入状态监控

### 灵活配置
- **触发模式**：内触发 / 外触发模式
- **采样参数**：可配置采样周期数和每周期采样点数
- **延时控制**：ADC采样延时、IO拉高/拉低延时精确控制
- **电源管理**：±5V电源和数字输出控制

### 数据管理
- **高效缓存**：预分配内存，优化百万级数据点处理
- **数据导出**：支持 CSV 格式导出，包含原始数据和计算结果
- **完整性校验**：数据包CRC校验确保传输可靠性

##  快速开始

### 1. 环境配置

```bash
# 安装 Qt 开发环境
# 下载并安装 FTDI D3XX 驱动

# 克隆项目
git clone https://github.com/softsister1/analog-signal-acquisition.git
cd analog-signal-acquisition
```

### 2. 编译项目

```bash
# 使用 Qt Creator 打开项目文件
# 或使用命令行编译
qmake CONFIG+=release
make
```

### 3. 运行程序

1. 连接 FT600 硬件设备
2. 启动应用程序
3. 点击"连接设备"
4. 配置采集参数
5. 开始数据采集

##  功能说明

### 采集配置
- **组选择**：A组（8通道）/ B组（4通道）
- **电源控制**：±5V电源开关控制
- **数字输出**：5V_EN / 3V3_CTRL 控制
- **延时设置**：
  - ADC采样延时：1.0-16.0μs
  - IO拉高延时：6.0-20.0μs  
  - IO拉低延时：1.0-13.0μs

### 采样参数
- **采样周期数**：1-10,000,000
- **ADC采样点数**：2-20
- **触发模式**：内触发 / 外触发

### 数据显示
- **多周期均值**：显示所有周期的平均波形
- **单周期数据**：显示指定周期的原始波形
- **实时温度**：NTC温度传感器监控
- **功率监测**：电压、电流、功率实时计算

## 🔧 核心算法

### 电压转换算法
```cpp
// 20位ADC，范围-5V到+5V
double voltage = static_cast<double>(signedValue) * 5.0 / 524288.0;
```

### 温度计算算法
```cpp
// NTC阻值转温度（Steinhart-Hart方程）
double temperature = 1.0 / (ln_ratio / B + 1.0 / T0) - 273.15;
```

### 功率计算
```cpp
// 实时功率计算
double power = voltage * current;
```

## 🐛 问题排查

### 常见问题

1. **设备连接失败**
   - 检查 FTDI 驱动是否正确安装
   - 确认 USB 线缆连接正常
   - 验证设备权限设置

2. **数据传输错误**
   - 检查 USB 3.0 接口性能
   - 调整传输缓冲区大小
   - 验证硬件电源供应

3. **界面响应慢**
   - 减少显示的数据点数量
   - 优化图表刷新频率
   - 检查系统内存使用情况
